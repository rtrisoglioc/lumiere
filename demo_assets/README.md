# LUMIÈRE — Demo Assets

Drop your **real** sample clips here to power DEMO_MODE. We do NOT synthesize test bars.

- Put a few short real clips (`.mp4`, `.mov`, `.webm`) in this folder. The
  "Load demo footage" button in an Experience will inject them as captured footage.
- Optionally add `fallback_cut.mp4` — a real pre-rendered film used as a fail-safe
  if a live render ever fails during the demo (so the screen is never blank).

Once your clips are here, tell the builder to wire the seeded demo Experience
(Lisbon: story + shots preloaded) so the pitch can start directly at "GET THE SHOT".
